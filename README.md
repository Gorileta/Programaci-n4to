# Programación - 4to Año

Repositorio de la materia de Programación. Vamos a arrancar desde los fundamentos de Python y vamos a cerrar el cuatrimestre (o el bloque) programando un juego usando todo lo aprendido.

## 📚 Contenidos

### 1. Introducción a Python
- ¿Qué es Python? Instalación y entorno de trabajo
- Sintaxis básica, comentarios
- Variables y tipos de datos (`int`, `float`, `str`, `bool`)
- Entrada y salida de datos (`input()`, `print()`)
- Operadores aritméticos, relacionales y lógicos

### 2. Estructuras de control
- Condicionales: `if`, `elif`, `else`
- Bucles: `for`, `while`
- Sentencias `break` y `continue`

### 3. Funciones
- Definición y llamado de funciones (`def`)
- Parámetros, argumentos y valores de retorno
- Alcance de variables (variables locales y globales)

### 4. Estructuras de datos
- **Listas**: creación, indexado, slicing, métodos (`append`, `remove`, `sort`, etc.)
- **Tuplas**: características y diferencias con las listas
- **Sets**: operaciones de conjuntos
- **Diccionarios**: claves y valores, métodos (`keys()`, `values()`, `items()`), recorrido con `for`

## 🎮 Proyecto final: Juego en Python

Como cierre de la unidad, vamos a diseñar y programar un juego integrando todos los conceptos vistos: variables, condicionales, bucles, funciones, listas y diccionarios.

**Ideas posibles de juego:**
- Ahorcado
- Piedra, papel o tijera
- Adivinar el número
- Preguntados / Trivia con diccionario de preguntas y respuestas
- Tres en raya (Tic-Tac-Toe)

*(La idea final se define en clase con el/la docente)*
